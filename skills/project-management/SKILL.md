# Project Management

Turn SEO insights into organized execution.

## Scoring framework
For each project, score 1-5:
- **Impact**: how much will this move the needle?
- **Effort**: how much work? (inverted: high effort = low score)
- **Confidence**: how sure are we this will work?
- **Urgency**: is there a time window?
- **Strategic fit**: does this align with `company-setup/seo-strategy.md`?

Priority = impact + confidence + urgency + strategic fit - effort.

## Project record structure
Page name, URL, project type, target query, hypothesis, recommended action,
impact/effort/confidence/urgency/fit scores, success metric, next step, notes.

## Output
Prioritized project list. If Airtable/Sheets is configured, format as importable records.
