# SEO Content Strategy

Transform SEO opportunities into content decisions and structured briefs.

## Core principles
- Intent first, keywords second.
- One page per primary intent.
- Differentiation is required to win. "Cover the same topics" is not a strategy.

## Decision framework
- **Create new** when: intent is not covered, topic deserves its own page, demand is strong.
- **Update existing** when: a page already ranks, improvements can push it higher.
- **Consolidate** when: multiple weak pages compete for the same intent.
- **Skip** when: low demand, poor fit, or unrealistic ranking potential.

## Brief structure
Title, target query, content type (new/update), search intent, content angle,
key sections (H2s), differentiation strategy, internal linking targets.
