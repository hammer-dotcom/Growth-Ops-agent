# Technical SEO

Audit the technical foundations that let search engines and AI systems crawl, render, index, and understand a site.

## Audit areas

1. **Crawlability**: robots.txt, internal linking, crawl depth, sitemap, HTTP status codes, redirect chains.
2. **Indexability**: canonicals, noindex directives, duplicates, thin pages, parameter handling.
3. **Rendering**: JS-dependent content, mobile rendering, hydration issues, lazy-loaded content.
4. **Performance**: LCP, INP, CLS. Identify causes (render-blocking resources, oversized JS, layout shifts).
5. **Structured data**: JSON-LD implementation, schema validity, entity alignment.
6. **AI-search readiness**: heading hierarchy, answer blocks, entity clarity, semantic structure.

## Output
Findings grouped by severity (critical/high/medium/low), each with: issue, explanation, SEO impact, recommended fix.
